    Hotkeys
    • Alt+Hover — peek
    • Alt+Click — capture
    • Alt+Drag — multi-stage
    • Alt+Shift+Click — stage one
    • Cmd+K — palette
    • Ctrl+F — find in list
    • Cmd+Z — undo · Cmd+Shift+Z — redo
    • Enter — send · Shift+Enter — newline
    • Esc — clear / cancel
    Help & about

    PinchGrab is an annotation tool for frontends. You point at the parts of a page that are wrong or could be better, leave a note in plain language, and hand the result to your AI coding agent so it can fix them from real human feedback.

    How to use it

    • Alt+Click an element on the page to capture it.
    • Type a comment in the composer to say what you want changed.
    • Export and give the file to your coding agent.

    Tip: edit DESIGN.md above so the agent rebuilds UI in your own brand. Full keyboard shortcuts live under Hotkeys.
